# Lexical sources

All the data used by the programs are in this folder. For each source we state where it comes from, which file is used and whether it is a copy of the public source or a file derived from it. **For an independent replication we recommend starting from the public sources**, obtained from their origin, and using the derived files only as a check.

The treatment of each file (which lines are used and how) is in `5_especificacion/FUNCTIONAL_SPECIFICATION_en.md`, section 1. This text is a translation of `LEEME_fuentes.md`.

## Iberian (`iberico/`)

| File | Content | Origin | Type |
|---|---|---|---|
| `unidades_plomos.json` | 30 units of the lead plaques: forms, proposed meaning, terms | The author's Monographs I–IV | Own |
| `unidades_numerales.json` | Numeral series: 10 units | Orduña (2005); Ferrer i Jané (2009, 2022) | Own, on the literature |
| `cldf/` | The 40 units (numeral series and lead plaques) in CLDF format, Wordlist module: forms, segments, sound classes, grade, source | The two files above | Own; same content as the two JSON files, in the exchange format of comparative linguistics |
| `hesperia_iberico_1599.csv` | Text of the 1,599 authentic Iberian inscriptions | Hesperia, Banco de datos de lenguas paleohispánicas (hesperia.ucm.es), consulted 7 Nov 2026 | **Not redistributed.** Generated by `descargar_hesperia.py` (below) |
| `hesperia_metadatos.csv` | Medium, material, script, site and dating of each record | Hesperia, consulted 12 Nov 2026 | **Not redistributed.** Generated by `descargar_hesperia.py`, with the normalised columns |
| `hesperia_formas_reducidas.json` | Public edition: sound-class-reduced forms of each record, with code, area, lead flag and script; no text | Derived from the two files above with `ibcomp.fuentes.hesperia()` | Minimal list; programs use it when the Hesperia files are absent |
| `descargar_hesperia.py` | Program that downloads the two files above from Hesperia and checks that they match, byte for byte (SHA-256), those used in the article | Own | Python 3 standard library only; about 40 minutes with courtesy pauses. `python3 descargar_hesperia.py` from this folder; `--solo-listado` for the first file only; `--cache DIR` keeps the raw HTML; `--verificar` checks the sums of files already present |
| `lexico_mlh_v2_clasificacion.csv` | Class of each form (personal name, mark, coin legend, etc.) | Moncunill and Velaza (2019), *Monumenta Linguarum Hispanicarum* V.2 | Derived: form and classification; used only in Tables 1 and 2 |
| `formantes_onomasticos_rodriguez_ramos_2014.json` | List of personal-name formants | Rodríguez Ramos (2014), *ArqueoWeb* 15 | Derived: list of formants |

## WordNet (`wordnet_mcr/`)

Multilingual Central Repository 3.0 (Gonzalez-Agirre, Laparra and Rigau 2012), in the Open Multilingual WordNet distribution. Files for Basque, Spanish, Catalan and Galician. CC BY 3.0. Unmodified copy.

## Apertium (`apertium/`)

Bilingual dictionaries for 19 language pairs, from the public Apertium repository (github.com/apertium). GPL licence. Unmodified copy of each `.dix` file. The list of files used is in `_archivos_usados.json`.

## NorthEuraLex (`northeuralex/`)

Dellert et al. (2020), Lexibank edition (github.com/lexibank/northeuralex). CC BY 4.0. Files `forms.csv` and `languages.csv`, unmodified.

## Numerals (`numerales_chan/`)

Chan (2019), *Numeral Systems of the World's Languages*, CLDF edition by Numeralbank (github.com/numeralbank/channumerals). CC BY 4.0. Files `forms.csv` and `languages.csv`, unmodified.

## Borrowability of meanings (`wold_prestabilidad_35_unidades.csv`)

Haspelmath & Tadmor (eds.) (2009), *World Loanword Database* (WOLD), Lexibank CLDF edition (github.com/lexibank/wold), file `cldf/parameters.csv`, column `Borrowed_score`. CC BY 4.0. Derived file: 35 rows (unit, WOLD meaning id and name, score), copied by hand on 21 Nov 2026 for the core-list meanings matching the units; the unit–meaning mapping was fixed and published before computing (`resultados/DECLARACIONES_PREVIAS.md`, entry 9).
